# EL NOSTRE UNIVERS — Instrucciones para Cursor

## Proyecto
Web interactiva infantil en catalán, publicada mediante GitHub Pages.

## Tecnología
- HTML, CSS y JavaScript nativos.
- Sin frameworks, servidores ni bases de datos.
- Sin dependencias externas salvo autorización expresa.
- Utilizar rutas relativas compatibles con GitHub Pages.
- Diseño adaptable, priorizando tablets en horizontal.

## Arquitectura
- Mantener una estructura de archivos sencilla.
- Separar HTML, CSS, JavaScript y recursos gráficos.
- Reutilizar componentes y funciones existentes.
- Separar el contenido de las aventuras de la lógica de programación.
- Evitar duplicar código.

## Interfaz
- Idioma de interfaz: catalán.
- Botones grandes, legibles y fáciles de tocar.
- Navegación coherente entre pantallas.
- Mantener el mismo aspecto para controles que realizan la misma acción.
- Evitar animaciones innecesarias.
- Sin publicidad ni enlaces externos dentro del juego.

## Forma de trabajar
- Implementar únicamente lo solicitado.
- No añadir funcionalidades por iniciativa propia.
- No modificar decisiones arquitectónicas sin autorización.
- No reescribir archivos completos cuando basten cambios localizados.
- Consultar únicamente los archivos necesarios para cada tarea.
- No realizar refactorizaciones no solicitadas.
- No instalar paquetes sin autorización.
- No generar documentación adicional salvo petición expresa.
- No ejecutar pruebas extensas si no son necesarias para el cambio.
- Mantener las respuestas breves.

## Al finalizar cada tarea
Indicar únicamente:
1. Archivos modificados.
2. Qué se ha implementado.
3. Errores o problemas detectados, si los hay.

## Prioridad
Código sencillo, funcional, mantenible y reutilizable.
Minimizar el consumo de tokens sin comprometer el funcionamiento.
